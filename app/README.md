# 員工同事假期管理網站

純前端、無登入的同事休假管理工具：記錄同事與休假日期、自動偵測同日多人放假衝突、提供提前提醒，並支援本機模式與可選的雲端跨裝置同步。

## 功能

- 同事與假單完整 CRUD（含半天 AM/PM、假別、備註）
- 同日多人放假自動偵測與衝突標示（可設閾值，預設 2 人）
- 提前提醒（站內提醒卡 + 儀表板，無 email / push）
- 個人休假月曆 + 團隊時間軸（Gantt 檢視）
- 週末自動排除、香港公眾假期內建（2026 / 2027）
- 唯讀分享模式（網址加 `?v=ro`）
- 本機模式自動降級；可選連接 Supabase 跨裝置同步
- 資料匯出 / 匯入 JSON

## 技術

Vite 5 + React 18 + TypeScript（strict）。手寫 CSS + 設計變數，不使用 Tailwind 或任何 UI 框架。

## 指令

- 開發：`npm install` 後 `npm run dev`
- 建置：`npm run build`（輸出至 `../site`）
- 單檔建置：`npm run build:single`（所有資源內聯為單一 HTML，便於隨身攜帶）
- 預覽：`npm run preview`
- 測試：`npm test`

## 部署

`site/` 為純靜態檔案，可直接託管於任意靜態空間（GitHub Pages、Netlify 等）。`base` 已設為 `./` 以支援子路徑部署。

## 隱私與安全

- 本網站無登入機制；連接 Supabase 時 anon key 會出現在瀏覽器原始碼中。
- RLS（A / B / C）僅提高門檻（header 可被偽造），防誤觸與一般窺探，不防惡意人士。
- 請勿在備註欄填寫身分證號、電話、住址、薪資、醫療證明等敏感個資。

## 已知限制

- 資料存放於瀏覽器本機（localStorage），清除瀏覽器資料會導致遺失；重要資料請務必匯出備份。
- 雲端同步為選用功能，未設定時自動使用本機模式，功能完全不變。
